# Wave 1 search archive — SRCH-0001 to SRCH-0005, run 2026-09-02

Referenced by `searches[].report_ref` in `project_state/literature.json`.

**What this file is for.** The registry holds what was *accepted*: the verified citations, the
novelty-matrix cells and their bases, the quoted figures and where each was read. It does not hold
what was *set aside*. That is what this file records — the excluded candidates, the out-of-window
rejections, and the things the searches could not resolve. An exclusion list nobody can see is
indistinguishable from a search that was too narrow.

**What this file is not.** These are search returns, not project facts. Nothing here is a project
fact until it is verified against a primary source and written into the registry with a verdict. The
verbatim queries, screening counts, inclusion and exclusion criteria for each search live in
`searches[]`, not here, because those are machine-checkable and this is not.

## Out-of-window candidates — rejected, reason `outside owner-mandated window 2022-2026`

Reported rather than omitted, because several are the true method ancestors of the project's claim and
an examiner may name them.

| Work | What it originates | Cost of omitting |
|---|---|---|
| **Andreas et al. (2016), *Neural Module Networks*, CVPR** | Assembles a question-specific network from typed reusable modules | **The most serious omission.** The nearest ancestor of "typed operators assembled into a per-case computation graph". Raised independently by two searches |
| **Hu et al. (2017), *Learning to Reason: End-to-End Module Networks*, ICCV** | A **layout policy predicts a per-instance network layout** that is then dynamically assembled | Structurally the Case Graph Compiler, nine years earlier, in visual question answering |
| Rahaman et al. (2021), *Dynamic Inference with Neural Interpreters*, NeurIPS | An explicit **signature and typing mechanism** over functions with input-dependent routing | The closest pre-window analogue to typed operators plus dynamic topology *inside a trained model* |
| Shazeer et al. (2017), sparsely-gated MoE, ICLR | The sparsely-gated MoE layer itself | Fedus 2022 and Mixtral 2024 both cite it as the origin |
| Lepikhin et al. (2021), GShard, ICLR | Top-2 MoE routing at scale | DeepSeekMoE's comparative claims are meaningless without it |
| Bengio et al. (2013), straight-through estimator | The technique `ARCHITECTURE_SPEC.md` §Training approach names without a source | The project's own spec references it uncited |
| Graves (2016) Adaptive Computation Time; Banino et al. (2021) PonderNet | Input-adaptive compute depth | The honest prior art for "not every case should use the same amount of computation" |
| Roller et al. (2021), Hash Layers, NeurIPS | The hash and random-routing control that LIT-0034 reuses | The origin of baseline family 4's control design |
| Teerapittayanon et al. (2016), BranchyNet, ICPR | Early exit | Covered in-window by the ACM Computing Surveys review |
| Ellis et al. (2021) DreamCoder and library learning | Operator-vocabulary learning over typed DSLs | Prior art for learning the operator library rather than fixing it |
| **Jacovi & Goldberg (2020)**, faithfulness definition, ACL | The canonical definition | **Fully replaced in-window** by LIT-0040 and LIT-0041. No cost |
| **Futoma et al. (2020)**, generalisation failure in clinical ML | Clinical ML does not generalise | **Replaced** by LIT-0047, and by a Nature Medicine 2023 piece arguing external validation should give way to recurring local validation |
| **Wong et al. (2021)**, sepsis model external validation, JAMA Intern Med | A deployed proprietary model failing in the field | **Replaced by LIT-0046, which is a better fit** — an emergency-department validation rather than an inpatient one |
| Subramanian et al. (2020), *Obtaining Faithful Interpretations from Compositional Neural Networks*, ACL | Because module parameters are learned end to end, there is no guarantee a module performs its intended operation | **A genuine partial gap.** No in-window paper reproduces this for typed modules directly; LIT-0042 and LIT-0045 are the closest cover |
| Vig et al. (2020), causal mediation in NLP; Adebayo et al. (2018), sanity checks; Goddard et al. (2012), automation bias; MTS validity review (2014); pooled-kappa triage meta-analysis (~2020) | Foundational method and evidence | Each covered in-window by a stronger record, except the MTS validity review — **MTS consequently has no in-window reliability evidence in this survey** |
