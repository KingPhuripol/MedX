## วิธีบันทึกหลักฐาน

1. ดาวน์โหลด Completion Report (ไม่ใช่ Completion Certificate อย่างเดียว — รายงานมีรายชื่อโมดูลและคะแนน)
2. บันทึกเป็น `sources/2026-09-XX_citi_<รหัสนักศึกษา>.pdf`
3. คำนวณ checksum แล้วกรอกลงตารางข้างบน:

```bash
shasum -a 256 sources/2026-09-XX_citi_<รหัสนักศึกษา>.pdf
```

4. ตรวจว่าชื่อในใบรับรองสะกดตรงกับเอกสารที่ใช้สมัคร PhysioNet ชื่อไม่ตรงทำให้คำขอ credentialing ถูกปฏิเสธ
5. อัปเดต `evidence` ของ `TASK-0011` ใน `project_state/tasks.json`

`sources/` อยู่ใน `.gitignore` โดยตั้งใจ ไฟล์ PDF จึงไม่ถูก commit — ตารางนี้คือหลักฐานที่ commit ได้
ว่าไฟล์ในเครื่องคือฉบับใด เช่นเดียวกับ `SUBMISSION_RECORD.md`
