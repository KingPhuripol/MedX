# Research Implementation Area

Research code belongs here after the Architecture/Training/Benchmark contracts and a task are accepted. Recommended modules are `data_interfaces/`, `encoders/`, `graph/`, `models/`, `training/`, `evaluation/`, and `configs/`, each with tests.

Do not place datasets, checkpoints, logs, or ad-hoc result tables in Git. Every run uses a validated manifest. Start with the fixed baseline and synthetic executor before dynamic or approximately 4B work.
