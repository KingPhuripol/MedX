# Project Management Path Rules

- Official dates in `project_state/official_deadlines.json` never move through routine planning.
- Synchronize readable PM documents and machine state; run Harness verification.
- `DONE` requires definition-of-done evidence and applicable reviewer acceptance.
- Expose blocked/overdue P0/P1, workload concentration, and decisions/approvals; never hide schedule risk.
- Cut P4 then P3; humans decide P0-P2 scope reduction.
