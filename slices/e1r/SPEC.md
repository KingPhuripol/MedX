The E1 reviewers set conditions that must close before `factory/e1` merges into `factory/int`. Every one of them closes **by disclosure only**. Frozen metrics, manifests, adapters and mapping are not changed, and the test split is not re-run: 0 new ledger lines.

## Scope

1. **Generator.** `eval/posthoc/e1_findings.py` (stdlib + `eval.exact` only, no `app.*`) reads only these inputs:
   - the stored outputs `eval/results/e1/{dev,test}/{system_outputs.jsonl, voice/predictions.jsonl, triage/predictions.jsonl, */results.json}`;
   - gold in `data/synthetic/v1/gold/`;
   - `eval/ledger/runs.jsonl`.

   Before computing, it checks that each stored `predictions.jsonl` / `results.json` sha256 equals the `predictions_sha256` / `results_sha256` in `runs.jsonl`, and refuses on mismatch. It records the sha256 of each `system_outputs.jsonl`. It writes `eval/results/e1/POSTHOC_FINDINGS.json` and a `.md` rendered from that JSON, so no number is hand-typed. `--check` regenerates both in memory and fails unless they are byte-identical to the committed files.
2. **Header.** Both files start with: `Post-hoc findings - computed after the frozen run from stored predictions; not part of the predeclared evaluation`. Each table also carries `System Evaluation on synthetic data - not clinical performance`.
3. **Sections.** The sections are:
   - **C-E1-1:** CC assertions hidden by exclusion; the SYNE-0196 trace.
   - **C-E1-2:** text red flags; silent escalations.
   - **C-E1-3:** degenerate F1; CC coverage.
   - **C2:** what the Voice rows measure.
   - **C3:** version and code bindings.
   - **C5:** dept `12` vs `NOT_EVALUABLE`.
   - **Defects filed for I2.**
   - **Headline for the progress report.**
4. **SYNE-0196 classification.** Classify the case as `S3_DEFECT`, `REPLAY_ARTIFACT` or `BOTH`, with evidence:
   - Stored evidence: span turn indexes and `handoff_reason`.
   - Code citations (file:line at `8943cd1`), at least:
     - `backend/app/voice/mock_rules.py` `_chief_complaint`, where the gate is `asked not in (None, "chief_complaint")`;
     - `backend/app/voice/service.py`, where `last_asked` is derived only from `speaker == "agent"` turns. The e1 replay has 0 agent turns.
   - An explanation of why turn 1 (which contains `อ่อนแรง`, a `fatigue` pattern) yielded no CC.
   - Optional: a diagnostic replay of **dev** SYNE-0196 only, in a test outside `eval/adapters/`, that writes nothing under `eval/results/` or `eval/ledger/`. Test-split cases (SYNE-0031) are analysed from stored outputs only.
5. **Tests.** `eval/tests/test_e1_posthoc.py` covers the cases in "Required test cases".

## Out of scope

- Any change to these, byte for byte:
  - `eval/manifests/e1/`, `eval/adapters/**` (including its tests: `adapters_sha256` hashes every `.py` there), `eval/adapters/mappings/`;
  - `eval/ledger/`, `eval/results/e1/{dev,test,unfrozen}/`, `eval/results/e1/e1_summary.{json,md}`;
  - `data/`, `backend/`.
- Any new freeze or run, and any execution of S3/S4 on test-split inputs.
- Fixing S3/S4. Defects are filed for I2, not repaired here.
- A new predeclared metric or verdict. Post-hoc numbers never replace a frozen value or verdict.
- The untracked `tests/e2e/e1_independent_check.py` in this worktree belongs to the e1 checker. Do not commit or edit it.

## Clinical risks

- **Understated safety gap (HIGH).** SYNE-0196 is a FAST-positive presentation routed to ORTHO/MED with no alert. The note must not call it fixed, rare or an artifact only, unless the evidence shows that. It remains an open I2 defect.
- **Misleading precision.** The frozen CC precision of 1.0 excludes the 3 wrong assertions. The all-assertion precision must sit next to it.
- **Silent escalation.** 13 gold-escalate DPs got a department suggestion with no alert. A nurse could read these as routine. The headline must say red-flag recall FAILs.
- **Over-claim.** This is a System Evaluation on synthetic data. No ASR, no clinician review, no clinical performance claim.
