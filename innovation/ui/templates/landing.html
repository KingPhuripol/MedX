ปัญหาที่หน้างาน OPD

ข้อมูลผู้ป่วยหลุดหายระหว่างทาง และทุกจุดต้องถามซ้ำ.

ซักประวัติซ้ำหลายจุด

พยาบาลคัดกรอง แพทย์ถามอีกรอบ ห้องยาถามเรื่องแพ้ยาอีกครั้ง เพราะข้อมูลไม่ได้ไปพร้อมผู้ป่วย

ยาต้องตรวจด้วยมือ

ประวัติแพ้ยาและยาที่ใช้อยู่มักเป็นข้อความอิสระ เภสัชกรต้องไล่เทียบเองทีละรายการ

กลับบ้านแล้วไม่รู้ว่าต้องกลับมาเมื่อไร

คำแนะนำอาการอันตรายมักเป็นคำพูด ผู้ป่วยจำไม่ได้ และไม่มีเอกสารให้ถือกลับ

ผู้บริหารไม่เห็นคอขวด

ไม่รู้ว่าผู้ป่วยค้างอยู่ขั้นไหน รอแพทย์หรือรอยา นานเท่าไร จนกว่าคิวจะล้น

เส้นทางผู้ป่วยใน MedX

ข้อมูลชุดเดียว เดินตามผู้ป่วยทุกสถานี.

หน้างาน / พยาบาล

พูดหรือพิมพ์ AI เสนอข้อมูลให้พยาบาลตรวจและยืนยันก่อนบันทึก

① Voice Agent

แพทย์

เห็นสรุปพร้อมหลักฐาน red flag ขึ้นก่อน ยืนยัน แก้ หรือปฏิเสธร่าง แล้วสั่งยาเอง

ทบทวนโดยแพทย์

ห้องยา

ระบบตรวจแพ้ยา ยาซ้ำ ยาตีกัน เภสัชกรตัดสินใจจ่าย พัก หรือติดต่อแพทย์

② Pharma Agent

Med Passport

สรุปทั้งเส้นทาง ยาที่ได้รับ และอาการที่ต้องกลับมา พิมพ์ได้และส่งออก FHIR

④ Universal Med Passport

กลับบ้าน

แพทย์บันทึกการตัดสินใจ กลับบ้าน ส่งต่อ หรือสังเกตอาการ ระบบไม่ตัดสินแทน

③ Dashboard ติดตามทุกขั้น
4 โมดูลที่ใช้งานได้วันนี้

ทุกโมดูลทำงานได้จริงในเดโม และกำหนดชัดว่าไม่ทำอะไร.

① VOICE AGENT

ซักประวัติด้วยเสียง

ถอดเสียงภาษาไทย แปลงเป็นข้อเท็จจริงที่มีโครงสร้าง แยก "ไม่ทราบ" "ปฏิเสธ" "ไม่มีข้อมูล" ออกจากกัน

ไม่ทำ: บันทึกเองโดยไม่ผ่านพยาบาล

② PHARMA AGENT

ตรวจยาก่อนจ่าย

กฎตายตัวตรวจแพ้ยา แพ้ข้ามกลุ่ม ยาซ้ำ ยาตีกัน แล้ว AI ช่วยสรุปให้เภสัชกร ข้อมูลที่ขาดจะไม่ถูกถือว่าปลอดภัย

ไม่ทำ: สั่งยา เปลี่ยนยา หรือจ่ายยาเอง

③ DASHBOARD

เห็นคอขวดแบบสด

ผู้ป่วยอยู่ขั้นไหน รอนานเท่าไรในแต่ละช่วง เคสไหนถูกยกระดับจาก red flag

ไม่ทำ: จัดลำดับการรักษาแทนแพทย์

④ MED PASSPORT ★

ใบเดียวติดตัวผู้ป่วย

สรุปที่แพทย์ยืนยัน ยาที่ได้รับ และอาการที่ต้องกลับมา พิมพ์ได้ และส่งออก FHIR R4 ตามโครง IPS

ไม่ทำ: ใส่ข้อมูลที่ยังไม่มีคนยืนยัน

ความปลอดภัยที่ออกแบบไว้ในระบบ

AI เสนอได้ แต่คนเป็นผู้ตัดสินเสมอ.

Red flag มาก่อนเสมอ

กฎคัดกรองแบบตายตัวทำงานก่อนโมเดลทุกครั้ง เคสที่ถูกยกระดับต้องมีเหตุผลจากแพทย์ก่อนปิดเคส

ข้อมูลที่ขาดไม่ใช่ "ไม่มี"

ไม่รู้ประวัติแพ้ยาหรือยาที่ใช้อยู่ ระบบจะไม่ให้ผลว่าไม่พบปัญหา และบอกชัดว่าต้องถามเพิ่ม

Agent ลดระดับความเสี่ยงไม่ได้

AI เรียกได้เฉพาะเครื่องมืออ่านข้อมูล มีโควตาทุกครั้ง เพิ่มข้อกังวลได้ แต่ลบผลตรวจของกฎไม่ได้

ตรวจย้อนหลังได้ทุกขั้น

ทุกการกระทำมีผู้ทำ เวลา และหลักฐาน บันทึกแบบเพิ่มอย่างเดียว เปิดดูกราฟการทำงานของ AI ได้

ไม่มีข้อมูลจากอนาคต

ข้อมูลทุกชิ้นมีเวลาที่พร้อมใช้ Passport ย้อนดู ณ เวลาใดก็ได้โดยไม่มีข้อมูลที่มาทีหลังปน

เปลี่ยนโมเดลได้โดยไม่แก้ระบบ

ทุกการเรียกโมเดลผ่าน Model Gateway เดียว เปลี่ยนผู้ให้บริการได้โดยหน้าจอและกฎความปลอดภัยไม่เปลี่ยน

→ยังไม่ผ่านการประเมินทางคลินิก ใช้กับข้อมูลสังเคราะห์เท่านั้น การใช้กับผู้ป่วยจริงต้องผ่านการประเมินทางคลินิกและคณะกรรมการจริยธรรมก่อน

ลองระบบจริง

เลือกบทบาท แล้วลองทำงานกับเคสตัวอย่างได้ทันที.

คุณจะได้พื้นที่ทดลองส่วนตัว พร้อมเคสสังเคราะห์ 4 เคสในขั้นตอนต่างกัน เปลี่ยนบทบาทได้ตลอดจากเมนูด้านซ้าย

⚠ ใช้ข้อมูลสมมติเท่านั้น ห้ามใส่ชื่อ เลขบัตร เบอร์โทร หรือ HN ของผู้ป่วยจริง ระบบจะปฏิเสธข้อความที่ดูเหมือนข้อมูลระบุตัวบุคคล ข้อมูลเดโมถูกล้างเป็นระยะ

โรงพยาบาลนำร่อง

นำ MedX ไปทดลองในแผนกผู้ป่วยนอกของคุณ.

  • ศึกษาการใช้งานร่วมกับพยาบาล แพทย์ และเภสัชกรในสภาพแวดล้อมจริงแบบมีการกำกับ
  • ปรับตำรับยาและกฎคัดกรองร่วมกับเภสัชกรและแพทย์ของโรงพยาบาล
  • เชื่อมต่อผ่าน API และส่งข้อมูลเป็น FHIR

ติดต่อทีมพัฒนา
